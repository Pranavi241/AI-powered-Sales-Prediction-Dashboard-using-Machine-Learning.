# AI-powered-Sales-Prediction-Dashboard-using-Machine-Learning.
“My project is an AI-powered sales prediction dashboard. It uses machine learning (Linear Regression) to predict future sales based on factors like month, price, discount, and advertising spend. I built a Streamlit dashboard where users can input business data and get real-time predictions. This helps small businesses make better decisions 
Features
 Sales prediction using ML
 Streamlit dashboard
 Business insights
How to Run
  pip install -r requirements.txt     streamlit run app.py

Files
 app.py
 train_model.py
 sales_model.pkl
 sales_data.csv
